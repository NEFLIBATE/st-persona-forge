# 用户设定工坊 · Persona Forge

为 **SillyTavern 用户设定（Persona）**设计的中文扩展。填写几个关键词，即可生成玩家扮演的人物身份，检查后新增到酒馆。

## v1.2.0 题材与性别选择

- 世界题材扩展到20种，新增武侠江湖、赛博都市、星际远航、末日求生、废土重建、蒸汽朋克、东方志怪、神话史诗、无限流副本、异能都市、娱乐演艺、航海探险、兽人奇幻。
- 表单统一显示“性别”，使用下拉选择：不指定、男、女、非二元、无性别、自定义。
- 自定义选项可填写具体性别；升级时保留旧版已填写的内容。
- 性别选择同时应用到免API模板和AI生成要求。

## v1.1.0 完整页面更新

- 页面铺满酒馆可用屏幕，顶部提供“创作设定／编辑与导出／草稿架”导航。
- 手机生成完成后自动定位到编辑区，可随时返回顶部或草稿。
- 界面与酒馆主题样式隔离，避免输入框颜色、字号被覆盖。
- 使用浏览器顶层页面容器，避免酒馆布局导致上半部分被裁切；适配手机动态视口与安全区域。
- 已安装用户在扩展管理中检查更新，更新后刷新酒馆。

## 功能

- 调用酒馆当前连接的模型生成或完善设定，无需在插件中填写 API Key。
- 20 种免 API 中文模板，覆盖日常、校园、修仙、武侠、西幻、科幻、末日、悬疑、志怪、演艺、航海等题材。
- 姓名、年龄、性别、身份、性格、关系和其他要求均可自定义。
- AI 支持简体中文、繁体中文、English，提供精简／标准／详细三种篇幅。
- 两种生成模式：独立创作；沿用当前聊天上下文与预设。可另行勾选参考当前单人聊天的角色卡。
- 生成后直接编辑；可读取已有 Persona 继续完善。
- 一键创建新的 Persona；可上传头像，无头像则生成姓名首字占位图。
- 草稿自动保存当前编辑内容，手动保存和替换时留存历史，最多50份。
- 导出酒馆原生 Persona 备份 JSON 或 TXT；导入原生备份 JSON 或单个 `{name,title,description}` 对象。
- 手机适配；可通过扩展设置或 `/persona-forge` 打开。

## 安装方法一：通过 GitHub

1. 在 SillyTavern 打开 **扩展 → 安装扩展**。
2. 粘贴下方仓库地址，完成安装后刷新酒馆：

```text
https://github.com/NEFLIBATE/st-persona-forge
```

3. 在扩展设置找到 **用户设定工坊 · Persona Forge → 打开用户设定生成器**。也可输入 `/persona-forge`。

无需 npm install 或打包构建。更新时在酒馆扩展管理中检查更新。

## 安装方法二：手动安装

停止酒馆，把项目文件夹命名为 `st-persona-forge`，放入以下任意一个位置后重启：

```text
SillyTavern/public/scripts/extensions/third-party/st-persona-forge/
```

或当前用户的数据目录：

```text
SillyTavern/data/<用户标识>/extensions/st-persona-forge/
```

安装后文件路径应为 `.../st-persona-forge/manifest.json`。服务端扩展、Extras 服务和额外 Node 依赖均不需要。

## 使用流程

1. 打开生成器，填写题材与人物要求。可以只写关键词，也可以全部留空。
2. 没有模型连接时，先点 **免 API 中文模板**，即可得到可编辑的完整初稿。
3. 有模型连接时，点击 **AI 生成／完善**。默认独立创作，不主动读取聊天。沿用上下文模式会使用当前聊天与酒馆预设；预设自身的行为可能影响输出。
4. 检查右侧姓名、标签和设定描述。再次生成会参考右侧已有内容；从头创作请先点 **新建设定**。
5. 选填头像，点击 **新增到酒馆**。这是新建操作；读取已有 Persona 后也会创建另一份。
6. 在酒馆 **用户设定管理** 中选择新设定。也可以事先勾选“新增后切换为当前用户设定”。切换时酒馆自身可能刷新空聊天的首条消息，或按原有设置自动锁定 Persona。

姓名与描述为必填；标签只用于列表显示。模板为中文；语言选项控制 AI 输出语言。

## JSON 导入与迁移

**导出酒馆 JSON** 生成原生备份结构：

```json
{
  "personas": { "persona-forge-唯一标识.png": "林澈" },
  "persona_descriptions": {
    "persona-forge-唯一标识.png": {
      "description": "完整设定描述",
      "title": "现代 · 旧友",
      "position": 0,
      "depth": 2,
      "role": 0,
      "lorebook": ""
    }
  }
}
```

该文件可在 **酒馆用户设定管理 → 恢复** 导入。JSON 不含头像；酒馆会为缺失头像使用默认图片。导出不会设置默认 Persona。每次导出分配新标识，因此反复导入不同导出文件可能产生多个相同姓名的设定。

生成器的 **导入 JSON** 仅将内容载入编辑器和草稿架；需要再点击“新增到酒馆”才会写入 Persona。最多接受2 MB、100条，草稿只保留最近50条；不支持把角色卡V2当作用户设定导入。

草稿与编辑内容存入酒馆用户设置。头像不写入草稿，刷新网页后须重新选择。备份迁移请使用 JSON；卸载插件前也可先导出要保留的草稿。已经创建的原生 Persona 不依赖本扩展继续工作。

## 兼容性与数据

- 声明最低 SillyTavern **1.13.0**。生成适配器兼容1.13的旧参数接口和当前版本的对象参数接口。
- 原生新增依赖酒馆的 `personas.js` 与头像上传接口。若未来酒馆更改内部接口，可使用 JSON 导出／恢复。
- 生成只通过酒馆当前连接进行，不内置第三方请求地址、API Key 或遥测。启用上下文／角色参考后，相关内容会随请求发送给当前连接的模型服务。
- AI 生成失败时保留原有编辑内容；头像上传成功后才创建 Persona。若提示“已新增但刷新失败”，先刷新酒馆查看，避免重复新增。
- 代码与模拟环境检查不等于在你的酒馆环境实测；首次安装后建议用免 API 模板创建一份测试设定，再验证模型生成。

## 检查

Node.js 22 或更新版本：

```bash
npm run check
npm test
```

测试覆盖原生 JSON 往返、模板、模型输出解析、无效输入、角色参考及新旧生成接口。GitHub Actions 会自动运行这些检查。

完整页面回归检查（开发时可选，需要额外安装浏览器测试工具）：

```bash
npm install --no-save playwright
npx playwright install chromium
npm run test:ui
```

覆盖全屏边界、主题隔离、320/360/393像素手机及横屏布局、顶部导航、视口高度变化、导入导出与模型／头像失败处理。接口使用模拟响应，不会调用付费模型。若使用系统 Chromium，可设置 `BROWSER_EXECUTABLE` 为其可执行文件路径。

代码结构：`index.js` 负责界面与酒馆接入，`core.js` 负责模板／解析／导入导出，`style.css` 负责桌面与手机布局。无外部前端依赖，无构建步骤。
